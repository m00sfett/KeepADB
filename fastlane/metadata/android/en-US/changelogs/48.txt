Webhook URLs are now redacted by one shared rule wherever they are shown. Query parameters are reduced to a marker, so a token passed as a parameter no longer appears on screen, and IPv6 addresses are hidden completely in every notation, including shortened forms, interface suffixes and bracketed ports. Log entries apply the same rule and no longer print IPv4 addresses unmasked. A webhook URL saved by an older version is cleaned up when it is read, not only when it is written: such a value is also used as the target when deregistering from a previous URL, so a user name and password contained in it could previously be sent over the network. Existing installations are covered without any action by the user (issue #350).
