Reconnecting to Wi-Fi now always requires a fresh check of the access point before wireless debugging is re-enabled automatically. Android does not guarantee that the loss of the old network is reported before the new one appears, so a new connection whose access point address was hidden from the app could briefly inherit the previous network's trust if the network names matched. Remembered trust is also no longer used while no Keep-Alive service is running to notice network changes. As a deliberate consequence, the network has to be recognizable once after a reconnect before automatic re-enable applies again (issue #354).
